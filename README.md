# Aplicativo Calculadora com Login

Projeto simples desenvolvido em Kotlin no Android Studio.

O aplicativo possui uma tela de login inicial e, após o acesso, abre uma calculadora simples com as operações básicas.

## Funcionalidades

- Tela de login com CPF e senha
- Calculadora com soma, subtração, multiplicação e divisão
- Botão para voltar para a tela inicial
- Botão para compartilhar o resultado
- Interface simples com tons de verde
